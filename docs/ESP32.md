# ESP32 输入使用说明

ESP32 的原生 USB 插在被控电脑上；Moonlight 客户端通过网络连接 ESP32。需要兼容的协议 2 NKRO16 固件，支持 16 个普通键与 8 个独立左右修饰键。

1. 添加并配对串流主机，在主机列表右键选择“ESP32 输入设置”。
2. 启用功能，填写设备地址、端口和 6 位控制密钥。按主机 UUID 保存，下一次串流生效。
3. 分别选择键盘和五个鼠标按钮。移动、滚轮和未接管的鼠标按钮仍通过 Moonlight 发送。
4. 键盘接管后使用独占路径；断线时阻止键盘发送，不自动绕回 Moonlight。固件不支持的按键也不会绕回原生路径。
5. 排除名单中的键仅留在本地。暂停、重连和释放全部的默认快捷键为 Ctrl+Alt+Shift+F9/F10/F11，可以更改或关闭。
6. 开启原性能统计栏（Ctrl+Alt+Shift+S），查看 ESP32 连接、暂停及键鼠路径状态。

原有 Ctrl+Alt+Shift+Q（退出）、Z（输入捕获）、X（全屏）继续有效。失焦、解除捕获和退出时释放输入；已断网时最终释放依赖固件约三秒看门狗。恢复连接后不重放旧的按住状态，应松开重按。

连接前退出旧 Bridge、其他客户端和 ESP32 控制网页，避免多个控制端争用。项目不分发个人密钥或启用的私人配置。

升级前保留原配置；Windows 便携版换目录时复制 `Moonlight Game Streaming Project` 设置文件夹，可保留配对和主机设置。v1.0 沿用兼容的协议 2 固件。
